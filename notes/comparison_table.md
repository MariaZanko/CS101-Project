# Порівняльна таблиця підходів

| Підхід | Які дані потрібні | Як вирішує cold start | Обмеження |
|---|---|---|---|
| Popularity, random | глобальна статистика взаємодій | показує найпопулярніше або випадкове | немає персоналізації; нові об’єкти не мають популярності |
| Опитування при реєстрації, bandit | відповіді користувача; відгуки на пробні покази | збирає початкові сигнали, свідомо досліджує нове | дратує користувача; ціна «дослідження» |
| Content-based і гібридні (LightFM) | ознаки об’єктів | вектор обчислюється з ознак | залежить від якості ознак; не використовує зв’язки |
| Глибокі з ознаками (DropoutNet, Heater) | ознаки + історія для навчання | під час навчання «вимикає» історію | потрібні якісні ознаки; чутливі до налаштувань |
| Meta-learning (MeLU, MAMO, MetaEmbedding) | багато задач із малою історією | швидко адаптується за кількома прикладами | складне навчання; потрібне формування задач |
| Графові (GCMC, IGMC, STAR-GCN, PinSage, гетерогенні GNN) | граф взаємодій і метаданих + ознаки | отримує сигнал від сусідів і зв’язків | обчислювальна вартість; залежить від якості зв’язків |
| Контрастне навчання (CLCRec) | ознаки + взаємодії | вирівнює простори ознак і взаємодій | складне налаштування; потрібні якісні пари |
