# Типи cold start

- **User cold start** — новий користувач без кліків і покупок: незрозуміло, що його цікавить.
- **Item cold start** — новий товар без взаємодій: система не знає, кому його показувати. Саме цей тип досліджує наш проєкт.
- **System cold start** — нова платформа без користувачів і історії.

## Cold start і sparsity

Sparsity (розрідженість) — взаємодії є, але їх мало. Cold start — історії немає зовсім. Це різні проблеми: у першому випадку сигнал слабкий, у другому його немає.

## Запасний варіант на практиці

Показувати популярне. Недолік: це не персоналізація, а для нових об’єктів популярність узагалі ще не накопичена.
