# Чому матрична факторизація не має вектора для нового ID

Модель вчить окремий вектор для кожного користувача (p_u) і кожного об’єкта (q_i). Оцінка пари — скалярний добуток:

    ŷ(u, i) = p_u · q_i

Вектор q_i коригується лише тоді, коли для i є взаємодії в навчальних даних. Новий об’єкт не має жодної взаємодії, тож його вектор залишається початковим (випадковим), і оцінки для нього не мають сенсу.

Висновок: потрібне додаткове джерело сигналу — ознаки об’єкта, його зв’язки в графі або інформація, зібрана іншим способом.
