## Слайд 7: Порівняльний аналіз GraphSAGE, GAT та LightGCN

### 1. GraphSAGE (SAmple and aggreGAtion)
* **Тип / Ключ:** Inductive (Семплювання + Агрегація)
* **Принцип роботи:** Для кожного вузла випадковим чином семплюється фіксована кількість сусідів ($1$-го, $2$-го порядку тощо), після чого їхні фічі агрегуються (через Mean, LSTM або Pooling).
* **Сильні сторони:** 
  * Висока масштабованість на великих графах.
  * Легко обробляє нові, раніше не бачені вузли.
* **Слабкі сторони:** 
  * Можлива втрата контексту через випадковий вибір сусідів.

### 2. GAT (Graph Attention Network)
* **Тип / Ключ:** Attention (Динамічні ваги)
* **Принцип роботи:** Динамічно розраховує важливість кожної ребра/сусіда за допомогою механізму Self-Attention.
* **Сильні сторони:** 
  * Висока точність завдяки адаптивним ваговим коефіцієнтам зв'язків.
* **Слабкі сторони:** 
  * Високі обчислювальні витрати $\mathcal{O}(\vert{}V\vert{} + \vert{}E\vert{})$ та складна оптимізація.

### 3. LightGCN (Light Graph Convolutional Network)
* **Тип / Ключ:** Collaborative Filtering Optimization (Спрощення без фіч)
* **Принцип роботи:** Спрощена модель для рекомендаційних систем без нелінійних активацій та вагових матриць $W$.
* **Сильні сторони:** 
  * Надшвидке навчання, ідеально для графічних задач рекомендацій (User-Item).
* **Слабкі сторони:** 
  * Повністю залежить від ID і топології графа, не використовує додаткові фічі вузлів.

> **Основне розрізнення:** GraphSAGE і GAT агрегують додаткові фічі вузлів, тоді як LightGCN оптимізує топологію графа взаємодій.

## Слайд 12: Поведінка GNN-моделей під час Cold Start

### Суть проблеми
Поява нових користувачів або товарів означає, що новий вузол має **0 зв'язків (ребер)** у графі взаємодій.

### Порівняльна поведінка моделей:

* **GraphSAGE — Відмінно (High Performance)**
  * **Механізм:** Навчає функції агрегації атрибутів.
  * **Результат:** Формує повноцінний ембеддинг на основі **метаданих вузла** (текст, категорії, анкета), навіть якщо ребер немає.

* **GAT — Задовільно (Moderate Performance)**
  * **Механізм:** Може використовувати початкові атрибути.
  * **Результат:** Працює з атрибутами, але механізм Attention втрачає ефективність через відсутність сусідів для порівняння.

* **LightGCN — Критично / Не працює (Fails)**
  * **Механізм:** Покладається лише на топологію графа та ID.
  * **Результат:** Без ребер новий вузол отримує лише випадково ініціалізований вектор.

> **Практичний висновок:** Для рекомендаційних систем із частим Cold Start застосовують гібридні підходи (наприклад, поєднання GraphSAGE для нових об'єктів та LightGCN для активної частини графа).
