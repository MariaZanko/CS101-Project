

## 1. Постановка проблеми Cold Start

У рекомендаційних системах граф взаємодій складається з двох типів вузлів — користувачів ($U$) та об'єктів/товарів ($I$), де ребра репрезентують фактичні дії (покупки, кліки, перегляди). 

**Проблема Cold Start (Холодний старт)** виникає при появі нових вузлів (нового користувача або нового товару):
* **Новий об'єкт / користувач не має жодних ребер в інтерлаг-графі**.
* Класична коллаборативна фільтрація спирається виключно на структуру зв'язків і повністю втрачає здатність формувати ембеддинги для таких вузлів.
* Для вирішення проблеми необхідно використовувати додаткові **атрибути/метадані вузла (Node Features)** (наприклад, текстовий опис, категорія, ціна, демографія) та індуктивний підхід до навчання.

## 2. Аналіз алгоритмів GNN

### 2.1 GraphSAGE (SAmple and aggreGAtion)

* **Механіка роботи:**
  Замість навчання статичного вектора для кожного ID вузла, GraphSAGE навчає **функцію агрегації** (Mean, LSTM, Pooling). На кожному шарі для вузла випадковим чином семплюється фіксована кількість сусідів $N(v)$, після чого їхні фічі об'єднуються з фічами самого вузла:
  $$h_v^{(k)} = \sigma \left( W^{(k)} \cdot \text{CONCAT} \left( h_v^{(k-1)}, \text{AGGREGATE}_k \left( \{ h_u^{(k-1)}, \forall u \in N(v) \} \right) \right) \right)$$

* **Переваги:**
  * **Масштабованість:** Семплювання обмежує ріст графа при розрахунках.
  * **Індуктивність (Inductive Learning):** Може отримати ембеддинг для абсолютно нового вузла, якщо відомі його початкові атрибути $h_v^{(0)}$.

* **Недоліки:**
  * Втрата частини топологічної інформації через випадкове семплювання сусідів.

* **Поведінка на Cold Start: Відмінно (High)**
  Завдяки використанню атрибутів ($h_v^{(0)}$) та навчених ваг $W^{(k)}$, GraphSAGE обчислює інформативний ембеддинг для нового об'єкта навіть за відсутності ребер взаємодії.

---

### 2.2 GAT (Graph Attention Network)

* **Механіка роботи:**
  Впроваджує механізм Self-Attention для розрахунку динамічної важливості (коефіцієнтів уваги $\alpha_{uv}$) кожного сусіда $u$ для вузла $v$:
  $$\alpha_{uv} = \frac{\exp\left(\text{LeakyReLU}\left(\mathbf{a}^T [W h_v \,||\, W h_u]\right)\right)}{\sum_{k \in N(v)} \exp\left(\text{LeakyReLU}\left(\mathbf{a}^T [W h_v \,||\, W h_k]\right)\right)}$$
  Агрегація здійснюється як зважена сума векторів сусідів.

* **Переваги:**
  * Висока точність завдяки адаптивним вагам сусідів.
  * Не потребує однакової важливості всіх ребер.

* **Недоліки:**
  * Високі обчислювальні витрати $O(|V| + |E|)$ та вимоги до пам'яті].

* **Поведінка на Cold Start: Задовільно (Moderate)**
  GAT вміє працювати з початковими фічами вузла, але його головна перевага — механізм уваги — не може розкритися, оскільки у нового вузла немає сусідів для порівняння та зважування.

---

### 2.3 LightGCN (Light Graph Convolutional Network)

* **Механіка роботи:**
  Спеціально розроблений для рекомендаційних систем. Прибирає вагові матриці $W$ та нелінійні активації $\sigma$, залишаючи лише просту агрегацію нормованого сусідства:
  $$e_v^{(k)} = \sum_{u \in N(v)} \frac{1}{\sqrt{|N(v)|}\sqrt{|N(u)|}} e_u^{(k-1)}$$
  Фінальний ембеддинг є зваженою сумою векторів на всіх шарах: $e_v = \sum_{k=0}^K \alpha_k e_v^{(k)}$.

* **Переваги:**
  * Надзвичайно висока швидкість навчання та простота.
  * SOTA-точність на графі взаємодій за наявності достатньої кількості ребер.

* **Недоліки:**
  * Повна відсутність використання атрибутів (Node Features); працює тільки з ID-ембеддингами.

* **Поведінка на Cold Start: Критично / Не працює (Fails)**
  Якщо у нового вузла немає ребер ($N(v) = \emptyset$), вектор не оновлюється під час передачі повідомлень (Message Passing) і залишається випадковим.

## 3. Порівняльна матриця моделей

| Критерій | GraphSAGE | GAT | LightGCN |
| :--- | :--- | :--- | :--- |
| **Основний механізм** | Семплювання + Агрегація | Self-Attention зважування | Нормована лінійна сума |
| **Використання Node Features** | Так (обов'язково) | Так | Ні (лише ID) |
| **Складність** | $O(B \cdot \prod_{l=1}^L S_l)$ | $O(\vert V \vert F + \vert E \vert F)$ | $O(\vert E \vert d)$ (дуже низька) |
| **Тип навчання** | Індуктивний (Inductive) | Індуктивний / Трансдуктивний | Трансдуктивний (Transductive) |
| **Ефективність Cold Start** | **Висока** | **Середня** | **Нульова** |

## 4. Практичні архітектурні рішення для Cold Start

1. **Гібридні моделі (Cold-Start Pipelines):**
   * Для активної частини графа використовують **LightGCN** (максимальна точність на наявних ребрах).
   * Для нових вузлів запускають **GraphSAGE** або MLP-проектор фіч у простір ембеддингів LightGCN.

2. **Гетерогенні мета-вузли (Meta-nodes):**
   * Додавання вузлів атрибутів (Бренд, Категорія, Теги) дозволяє зв'язати новий товар зі старими через спільний бренд, створюючи ребра навіть без фактичних покупок.
