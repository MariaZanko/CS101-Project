

## 1. Постановка проблеми Cold Start

У рекомендаційних системах граф взаємодій складається з двох типів вузлів — користувачів ($U$) та об'єктів/товарів ($I$), де ребра репрезентують фактичні дії (покупки, кліки, перегляди). 

**Проблема Cold Start (Холодний старт)** виникає при появі нових вузлів (нового користувача або нового товару)[cite: 3]:
* **Новий об'єкт / користувач не має жодних ребер в інтерлаг-графі**[cite: 3].
* Класична коллаборативна фільтрація спирається виключно на структуру зв'язків і повністю втрачає здатність формувати ембеддинги для таких вузлів[cite: 3].
* Для вирішення проблеми необхідно використовувати додаткові **атрибути/метадані вузла (Node Features)** (наприклад, текстовий опис, категорія, ціна, демографія) та індуктивний підхід до навчання[cite: 3].

## 2. Аналіз алгоритмів GNN

### 2.1 GraphSAGE (SAmple and aggreGAtion)

* **Механіка роботи:**
  Замість навчання статичного вектора для кожного ID вузла, GraphSAGE навчає **функцію агрегації** (Mean, LSTM, Pooling)[cite: 3]. На кожному шарі для вузла випадковим чином семплюється фіксована кількість сусідів $N(v)$, після чого їхні фічі об'єднуються з фічами самого вузла[cite: 3]:
  $$h_v^{(k)} = \sigma \left( W^{(k)} \cdot \text{CONCAT} \left( h_v^{(k-1)}, \text{AGGREGATE}_k \left( \{ h_u^{(k-1)}, \forall u \in N(v) \} \right) \right) \right)$$

* **Переваги:**
  * **Масштабованість:** Семплювання обмежує ріст графа при розрахунках[cite: 3].
  * **Індуктивність (Inductive Learning):** Може отримати ембеддинг для абсолютно нового вузла, якщо відомі його початкові атрибути $h_v^{(0)}$[cite: 3].

* **Недоліки:**
  * Втрата частини топологічної інформації через випадкове семплювання сусідів[cite: 3].

* **Поведінка на Cold Start: Відмінно (High)**
  Завдяки використанню атрибутів ($h_v^{(0)}$) та навчених ваг $W^{(k)}$, GraphSAGE обчислює інформативний ембеддинг для нового об'єкта навіть за відсутності ребер взаємодії[cite: 3].

---

### 2.2 GAT (Graph Attention Network)

* **Механіка роботи:**
  Впроваджує механізм Self-Attention для розрахунку динамічної важливості (коефіцієнтів уваги $\alpha_{uv}$) кожного сусіда $u$ для вузла $v$[cite: 3]:
  $$\alpha_{uv} = \frac{\exp\left(\text{LeakyReLU}\left(\mathbf{a}^T [W h_v \,||\, W h_u]\right)\right)}{\sum_{k \in N(v)} \exp\left(\text{LeakyReLU}\left(\mathbf{a}^T [W h_v \,||\, W h_k]\right)\right)}$$
  Агрегація здійснюється як зважена сума векторів сусідів[cite: 3].

* **Переваги:**
  * Висока точність завдяки адаптивним вагам сусідів[cite: 3].
  * Не потребує однакової важливості всіх ребер[cite: 3].

* **Недоліки:**
  * Високі обчислювальні витрати $O(|V| + |E|)$ та вимоги до пам'яті[cite: 3].

* **Поведінка на Cold Start: Задовільно (Moderate)**
  GAT вміє працювати з початковими фічами вузла, але його головна перевага — механізм уваги — не може розкритися, оскільки у нового вузла немає сусідів для порівняння та зважування[cite: 3].

---

### 2.3 LightGCN (Light Graph Convolutional Network)

* **Механіка роботи:**
  Спеціально розроблений для рекомендаційних систем[cite: 3]. Прибирає вагові матриці $W$ та нелінійні активації $\sigma$, залишаючи лише просту агрегацію нормованого сусідства[cite: 3]:
  $$e_v^{(k)} = \sum_{u \in N(v)} \frac{1}{\sqrt{|N(v)|}\sqrt{|N(u)|}} e_u^{(k-1)}$$
  Фінальний ембеддинг є зваженою сумою векторів на всіх шарах: $e_v = \sum_{k=0}^K \alpha_k e_v^{(k)}$[cite: 3].

* **Переваги:**
  * Надзвичайно висока швидкість навчання та простота[cite: 3].
  * SOTA-точність на графі взаємодій за наявності достатньої кількості ребер[cite: 3].

* **Недоліки:**
  * Повна відсутність використання атрибутів (Node Features); працює тільки з ID-ембеддингами[cite: 3].

* **Поведінка на Cold Start: Критично / Не працює (Fails)**
  Якщо у нового вузла немає ребер ($N(v) = \emptyset$), вектор не оновлюється під час передачі повідомлень (Message Passing) і залишається випадковим[cite: 3].

## 3. Порівняльна матриця моделей

| Критерій | GraphSAGE | GAT | LightGCN |
| :--- | :--- | :--- | :--- |
| **Основний механізм** | Семплювання + Агрегація[cite: 3] | Self-Attention зважування[cite: 3] | Нормована лінійна сума[cite: 3] |
| **Використання Node Features** | Так (обов'язково)[cite: 3] | Так[cite: 3] | Ні (лише ID)[cite: 3] |
| **Складність** | $O(B \cdot \prod_{l=1}^L S_l)$[cite: 3] | $O(|V|F + |E|F)$[cite: 3] | $O(|E|d)$ (дуже низька)[cite: 3] |
| **Тип навчання** | Індуктивний (Inductive)[cite: 3] | Індуктивний / Трансдуктивний[cite: 3] | Трансдуктивний (Transductive)[cite: 3] |
| **Ефективність Cold Start** | **Висока**[cite: 3] | **Середня**[cite: 3] | **Нульова**[cite: 3] |

## 4. Практичні архітектурні рішення для Cold Start

1. **Гібридні моделі (Cold-Start Pipelines):**
   * Для активної частини графа використовують **LightGCN** (максимальна точність на наявних ребрах)[cite: 3].
   * Для нових вузлів запускають **GraphSAGE** або MLP-проектор фіч у простір ембеддингів LightGCN[cite: 3].

2. **Гетерогенні мета-вузли (Meta-nodes):**
   * Додавання вузлів атрибутів (Бренд, Категорія, Теги) дозволяє зв'язати новий товар зі старими через спільний бренд, створюючи ребра навіть без фактичних покупок[cite: 3].
