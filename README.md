# CS101-Project

Холодний старт (cold start) — ситуація, коли рекомендаційній системі бракує історії взаємодій, щоб надійно рекомендувати. Розрізняють три типи:
• User cold start — новий користувач без кліків і покупок.
• Item cold start — новий товар, фільм чи заклад без взаємодій. Саме на ньому зосереджена наша презентація.
• System cold start — нова платформа, де немає ні користувачів, ні історії. 

Існує й інший варіант: об’єкт має лише кілька взаємодій, і сигнал надто слабкий.
Чому класичні методи не справляються. Collaborative Filtering і матрична факторизація вчать окремий вектор (embedding) для кожного ID користувача й товару. Прогноз має вигляд скалярного добутку цих векторів. Для нового товару вектор ніколи не навчався, бо немає прикладів, від яких можна було б учитися. Звідси випадкові рекомендації або запасний варіант «показати популярне».
Що пропонує графовий підхід. Дані подаються як граф: користувачі, товари, категорії, бренди, теги, міста — вузли, а взаємодії й належності — ребра. GNN обчислює представлення вузла як функцію його власних ознак і ознак сусідів (message passing). Новий товар ще не має покупців, але вже пов’язаний із брендом, категорією й тегами, тож може отримати осмислений вектор і потрапити до персоналізованого списку.
