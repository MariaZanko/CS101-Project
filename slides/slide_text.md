# Текст слайдів 3–4

## Слайд 3. Холодний старт: що це і чому класичні методи тут слабкі

1) Три типи cold start
- User cold start: новий користувач, ще немає кліків і покупок
- Item cold start: новий товар, немає взаємодій 
- System cold start: нова платформа, немає ні користувачів, ні історії

Cold start ≠ sparsity: історії немає зовсім ≠ історії мало

2) Чому CF і матрична факторизація тут не працюють
- ŷ(u,i) = p_u · q_i, вектор на кожен ID
- Вектор кожного ID навчається на взаємодіях
- Новий ID: взаємодій немає, вектор не навчений (випадковий)
- Запасний варіант: Popularity, але без персоналізації
