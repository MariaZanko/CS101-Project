# Schein et al. (2002): Methods and Metrics for Cold-Start Recommendations

**Дані:** Schein, Popescul, Ungar, Pennock. SIGIR 2002. Знайти в ACM Digital Library за назвою.

**Про що:** Рання робота, у якій cold start розглядається як окрема задача. Автори пропонують підхід, що поєднує колаборативні дані й вміст об’єктів, і вводять метрику для оцінювання рекомендацій у cold start.

**Як використано:** Слайд 3: посилання на постановку проблеми й на те, що cold start потребує окремої оцінки.

**Що перевірити в тексті:** точна назва запропонованої метрики та моделі; які дані використовували автори.
